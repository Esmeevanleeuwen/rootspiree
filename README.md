# Rootspiree · LevelUp World

Een Nederlandstalig sociaal spel in React. Maak een spelersprofiel, ontdek je speelstijl en kies een persoonlijk doel. De spelleider kan opdrachten toewijzen, inzendingen beoordelen en feedback geven.

## Lokaal starten

Gebruik Node.js 22.12 of hoger.

```sh
npm ci
npm run dev
```

Open het lokale adres dat Vite toont. Met `npm run build` maak je een productiebuild in `dist/`. Met `npm run preview` bekijk je die build lokaal. `npm test` controleert de spelregels.

## Het spel proberen

- Kies **Account aanmaken** voor een eigen profiel met zestien stellingen. De vier voorkeuren geven richting aan je opdrachten. Bij gelijke scores staat er een X op die plaats.
- Stap aan boord, ontdek je huis en leg een doel en een eerste actie vast in je veldboek. In je kamer kun je een oefening aan je opdrachten toevoegen.
- Wissel bovenaan naar **Spelleider** om een opdracht toe te wijzen of een inzending te beoordelen. Bij **Kampvuur** kunnen spelers berichten plaatsen en waardering geven.

Dit is een browserdemo. Profielen, opdrachten en berichten worden lokaal bewaard. De actieve rol en een onafgemaakte test blijven in het huidige tabblad bewaard. De spelers- en rolkeuze is bedoeld om het ontwerp uit te proberen. Er is geen serverlogin of synchronisatie tussen apparaten. De persoonlijkheidstest gebruikt eigen spelvragen die op MBTI zijn geïnspireerd.
